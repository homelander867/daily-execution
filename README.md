# 每日执行力计划

一个为 iPhone 优先设计的本地优先 PWA：课程表、每日任务、真实打卡、连续统计、睡前复盘和 JSON 备份。

## 永久访问

<https://homelander867.github.io/daily-execution/>

在 iPhone Safari 打开后，点「分享 → 添加到主屏幕」。

## 重要说明

- 这是纯静态 PWA，没有账号、服务器或云同步。
- 任务、课程、打卡和复盘只保存在当前浏览器的 localStorage。
- 清理 Safari 网站数据、换设备、换浏览器或换域名都会导致数据不可见。
- 请定期在「更多 → 导出完整 JSON 备份」保存备份。
- 全部自排课程没有固定时间，应用不会编造排程；节次时间是可修改的参考值。

## 更新网站

源码构建后，把 `dist/` 中的文件覆盖到本仓库根目录即可。每次构建会更新 Service Worker 缓存版本，手机联网刷新一两次后生效。
